# Freedom Fighters - Practica prueba formativa

## Como ejecutar
1. python -m venv .venv
2. Activar entorno: source .venv/bin/activate (o .venv\Scripts\activate)
3. pip install -r requirements.txt
4. python manage.py migrate
5. python manage.py runserver
